# 续局全员确认门禁

继续对局不再立即开新局：终局后进入续局等待，所有远程座位确认加入（或座位被处理）后，主机才正式开启新对局。

## 背景

第一版「继续对局」在终局后直接以旧座位建新局。终局时远程座位凭证按规格作废，客人轮询新对局拿不到座位，只能停留在「对局结束」画面——客人事实上被挡在新对局之外。同时，直接拉人入局违背"下一局要等人齐"的预期。

## 决策

- **续局等待阶段**：房间新增 `rematch` 阶段。主机在终局画面点「继续对局」进入该阶段，不产生新对局；远程座位逐一等待客人选择。
- **续局确认**：客人弹窗「加入对局 / 离开对局」。加入 → 座位标记已确认并轮换座位凭证；离开 → 座位转开放占座（显示名清除、凭证作废），新人凭房间号占下后即为已确认。
- **终局凭证保留**：终局不再立即作废远程凭证，保留到续局等待结束（加入→轮换；离开/主机改配→作废；放弃续局/开新房→随房作废）。刷新页面的客人仍能被认回原座位；待确认座位只对其原占有人开放，持码陌生人无法抢占。
- **开局门禁**：续局等待中的「开始新对局」要求有效真人座位 2–6、无开放空槽、无待确认座位。
- **不设自动超时**：不响应的座位由主机手动改为开放或关闭（复用现有座位配置）。

## 备选

- 立即开新局并自动拉入客人：终局凭证作废后客人无法重入；体验断裂，被否决。
- 立即开新局 + 对局内暂停等人：对局实体已生成却冻结，机制复杂，被否决。
- 续局等待加自动超时转开放：误伤挂机回头的客人，且引入新计时体系，被否决。
