# 原型化核心对局体验

Type: prototype
Mode: HITL
Status: resolved
Blocked by: 03

## Question

使用占位卡面时，桌面布局、行动选择、角色声明、质疑/阻挡窗口、卡牌失去与淘汰反馈应如何呈现和动效衔接，才能达到用户所说的“大巴扎式”流畅、清晰且可展示的核心体验？

## Answer

选定 **策划桌布局（变体 B）**，并并入变体 A 的右侧对局记录与顶栏规则介绍。参考《The Bazaar》只取“操作顺滑、材质精致、反馈克制”，不做碰撞、粒子连锁或夸张镜头。

抛弃式原型位于 [prototypes/core-match](../prototypes/core-match/)，运行：

```powershell
node .scratch/coup-ai-mvp/prototypes/core-match/server.mjs
```

默认打开 `http://127.0.0.1:4173/?variant=B`。

### 布局

- 左侧：Agent 座位竖向列表，显示名称、模型、钱币、公开/背牌与状态。
- 中央：行动舞台；声明进入中央焦点；响应时出现紧凑响应条（质疑 / 阻挡 / 放弃），不遮挡桌面。
- 下方：本地手牌 + 固定合法行动栏；需要目标时高亮可选座位。
- 右侧：对局记录（来自变体 A）。
- 顶栏：规则介绍按钮，打开基础版规则摘要面板（可 Esc / 点击遮罩关闭）。

### 视觉与动效

- 深色权谋风：炭黑/深蓝背景、暖金边线、低饱和角色色、纸张质感占位卡。
- 普通位移约 200–300ms；质疑亮牌、洗回与补牌约 600–900ms。
- 默认平衡节奏，提供整局快速模式；尊重 `prefers-reduced-motion`。

### 明确不做

- 卡牌碰撞、粒子爆发、电影镜头推拉。
- 模态遮挡式响应（除非打开规则面板）。
- 原版卡图；仅用占位卡面。
