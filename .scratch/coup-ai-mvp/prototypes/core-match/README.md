# PROTOTYPE — 核心对局体验

问题：使用占位卡面时，怎样让《政变》的行动、响应、质疑亮牌和补牌流程流畅、清晰且有质感？

## 运行

```powershell
node .scratch/coup-ai-mvp/prototypes/core-match/server.mjs
```

浏览器会打开 `http://127.0.0.1:4173/?variant=B`。

## 选定方案

- **B — 策划桌**：左侧座位列表、中央行动舞台与响应条、底部手牌与合法行动栏。
- 并入 A 的右侧对局记录。
- 顶栏提供「规则介绍」，打开基础版规则摘要面板。

对照变体仍可通过底部切换器查看：`A` 上方横排座位，`C` 放大当前声明。

此目录是抛弃式原型，不是生产代码，不含真实规则引擎、后端或持久化。
