# 定义 Agent 策略配置与可玩质量

Type: grilling
Mode: HITL
Status: resolved
Blocked by: 06

## Question

MVP 是否提供不同的 Agent 策略、人格或难度配置；若提供，它们应如何进入不包含公开发言的座位提示，并用哪些可复现对局指标判断 OpenCode、Claude 及其不同模型已经达到可玩的决策质量？

## Answer

超出本轮 MVP 目的地范围，不在本路线上解决。

本轮 MVP 使用统一默认座位提示，不提供人格、难度或策略档位；验收只要求 Agent 在工具禁用与协议约束下产出合法座位决策并完成对局流程，不设立牌力或胜率门槛。相关能力若需要，应在新的后续努力中单独制图。
