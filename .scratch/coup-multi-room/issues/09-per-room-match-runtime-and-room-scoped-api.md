# 09 — per-room 对局运行时与房间作用域对局 API（服务端）

**What to build:** 服务端按房间持有对局运行时；开局、轮询、决策、心跳、离席处置、终局与技术中止全部按房号路由；对局端点携带房间号；两个房间可同时进行对局且互不干扰。

**Blocked by:** 06 移除单 run 不变量, 07 presence 房间作用域键, 08 多房建房与大厅并行

**Status:** ready-for-agent

- [ ] 两房先后开局各自产生独立对局；第二房开局不中止第一房
- [ ] 对局轮询与决策端点带房间号；A 房座位凭证无法读取或提交 B 房对局
- [ ] 心跳/离席/回席/处置只作用于目标房，不清除他房在场状态
- [ ] 一房终局或技术中止不删除他房运行时与在场状态
- [ ] 原有单房对局行为回归不变：决策、终局、续局等待
