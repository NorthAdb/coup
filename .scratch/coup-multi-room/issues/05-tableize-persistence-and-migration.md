# 05 — 持久化表化与旧数据迁移

**What to build:** 服务端把「单行房间」持久化改为按房间号存储的房间表，对局运行记录增加房间号归属，两者都支持按房间读写与查询；启动时一次性把旧数据迁移到新形态，任何损坏都显式报告而不静默丢失。

**Blocked by:** None — 可立即开工

**Status:** done

- [ ] 房间按房间号主键存取，保存/加载/清除均为房间维度，可一次读取全部房间
- [ ] 对局运行记录带房间号：可「按房间查进行中 run」，同房至多一个进行中、不同房可并存
- [ ] 启动迁移：旧单行房间迁入新表；旧对局按旧房间的 matchId 回填房间号；无法归属的旧 run 标记迁移异常且不得被恢复
- [ ] 迁移遇损坏数据：保留旧数据并返回启动级迁移失败，不静默丢失
- [ ] 迁移完成后旧表不再被运行时读取
