# 21 — Agent 超时重试与中止节奏

**What to build:** 真 Agent 决策首次限时 30 秒，可恢复错误再试 15 秒；界面只显示思考/重试等状态；仍失败则技术中止且无胜者，并可走已有快照恢复。

**Blocked by:** 17 或 18（真 Agent）；20 — 持久化、事件回放与快照恢复

**Status:** ready-for-agent

- [ ] 首次 30 秒硬截止，可恢复错误仅重试一次 15 秒
- [ ] 迟到响应丢弃；非法决策不改变权威状态
- [ ] 不可恢复错误立即技术中止
- [ ] 用户可见状态不含思维链或原始敏感错误
- [ ] 中止后可从故障前快照恢复
