# PROTOTYPE — 大厅加入与离线重连提示

问题：局域网「双入口 → 创建房间/加入 → 大厅占座与主机开局门禁 → 对局中离线等待/重连提示」的信息架构与关键文案应长什么样？

三套结构差异明显的变体，底部切换器切换；对局桌仅 stub，不重做策划桌。

## 运行

```powershell
node .scratch/coup-lan-multiplayer/prototypes/lobby-join-reconnect/server.mjs
```

浏览器打开 `http://127.0.0.1:4174/?variant=B`。

## 选定方案

- **B — 指挥台**：入口左大「创建房间」、右「加入 / 本机」；大厅左邀请+门禁、右座位矩阵；对局断线用右侧抽屉承载等待与主机处置。

对照变体仍可通过底部切换器查看：`A` 流程条，`C` 圆桌场。
