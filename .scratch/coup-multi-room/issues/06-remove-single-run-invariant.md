# 06 — 移除单 run 不变量

**What to build:** 去掉「开局即中止上一个进行中对局」的全局保护：建房开局与对局创建回调都不再触碰其他对局的持久化记录，同一时刻允许多个进行中 run 并存。

**Blocked by:** 05 持久化表化与旧数据迁移

**Status:** ready-for-agent

- [ ] 新对局创建不再中止任何其他进行中 run
- [ ] 对局创建/提交回调只处理当前房间的 run，不猜测全局「上一个对局」
- [ ] 同房续局语义保持：同一房间重开仍按既有门禁结束其上一 run
- [ ] 存储层出现多个进行中 run 时，按房间查询互不串扰
