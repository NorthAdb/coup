# 24 — 座位呼出

**What to build:** 任一座位（含本地人类）作出一次公开决策后，该座位旁出现短暂座位呼出，约 4 秒后消失；同一座位若连续决策，新呼出直接替换旧的。玩家不必紧盯右侧对局记录也能跟上刚刚发生的选择（行动、质疑、阻挡、放弃、证明/认输、揭示等）。

**Blocked by:** None — can start immediately

**Status:** resolved

- [x] 每个座位的公开决策结果均可触发该座位旁的座位呼出
- [x] 呼出停留约 4 秒；同一座位后来的呼出替换前一条（不排队）
- [x] 呼出文案只反映已生效的公开选择，不含决策说明、隐藏牌或其他私有信息
- [x] 右侧权威对局记录仍完整可用；呼出不替代记录，也不改领域事件形状
- [x] 尊重减少动态效果时，呼出仍可读（可缩短或去掉动效，但不丢信息）

## Answer

表现层根据公开事件生成座位呼出（`seatCalloutFromEvent` / `seatCalloutsFromEvents`）；`calloutHoldMs` 平衡约 4s、快速缩短、减动效仍保留可读时长。MatchDesk 按座位替换展示，不改领域事件与右侧记录。
