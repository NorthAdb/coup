# 钉死房间码格式与加入链接形态

Type: grilling
Mode: HITL
Status: resolved
Blocked by: 02

## Question

在「短码 + 主机展示含 IP/端口的加入链接、不做 mDNS」已定的前提下，房间码的字母表与长度、加入链接的 URL 形状、多网卡时默认展示策略，以及局域网监听端口策略（固定/可配置/随机）应如何写进规格，才能让客人最少踩坑地加入？

## Answer

- **房间号**：4 位纯数字，创建时随机；与已有房间冲突则重抽。
- **加入链接**：`http://<lan-ipv4>:<port>/join?code=####`；主机 UI 一键复制；另单独展示房间号。
- **多网卡**：枚举非 loopback Preferred IPv4 后启发式默认（RFC1918 优先 `192.168/16`→`10/8`→`172.16/12`，存在其它候选时排除常见虚拟适配器名）；主机可手选并刷新链接；无候选则报错，不填 `127.0.0.1`。
- **端口**：主机模式默认尝试 **8787**；占用则回退 OS 随机端口并在 UI/链接展示实际端口。本机对战可续用随机 loopback 端口。第一版不做用户可配置端口。
- **手动加入**：完整加入链接，或手填主机地址（`IP:端口`）+ 房间号；禁止仅房间号提交。
