# 原型化大厅加入与离线重连提示

Type: prototype
Mode: HITL
Status: resolved
Blocked by: 04, 05, 06

## Question

用抛弃式低保真可点击原型，局域网「双入口 → 创建房间/加入 → 大厅占座与主机开局门禁 → 对局中离线等待/重连提示」的信息架构与关键文案应长什么样，才能让人直觉完成加入并理解断线后续玩？对局桌本身以复用现策划桌为主，不在本原型重做。

## Answer

选定 **B — 指挥台**（见 [prototypes/lobby-join-reconnect](../prototypes/lobby-join-reconnect/)）。

信息架构约定写入规格时对齐该变体：

- **入口**：左大区主推「创建房间」，右侧次要「加入房间」与「本机对战」。
- **加入**：链接粘贴为主，旁侧手填「地址 + 房间号」；禁止仅房间号。
- **主机大厅**：左栏固定邀请（大号房间号、复制链接、网卡手选）+ 开局门禁；右栏 3×n 座位矩阵，槽可切开放/Agent/关闭。
- **客人大厅**：左栏己席/改名，右栏只读座位矩阵；无开局按钮。
- **对局中离线**：策划桌复用区 + 右侧抽屉承载重连/离席文案与主机四处置（继续等待 / 换 Agent / 技术中止 / 强制揭示淘汰）。

对照未采用：A 流程条（过线性）、C 圆桌场（占座与门禁不如矩阵清晰）。
